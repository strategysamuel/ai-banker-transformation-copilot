# Contributing to AI Banker Transformation Copilot

Thank you for your interest in contributing to AI Banker Transformation Copilot!

We welcome contributions that improve the project's functionality, security, documentation, testing, accessibility, and responsible use of AI in banking.

## 1. How to Contribute

You can contribute by:

- Reporting bugs and technical issues.
- Suggesting new features.
- Improving documentation.
- Adding or improving automated tests.
- Improving RAG retrieval, policy versioning, and citation accuracy.
- Identifying security vulnerabilities through responsible disclosure.

## 2. Getting Started

1. Fork this repository.
2. Clone your fork.
3. Create a dedicated feature branch.
4. Install the project dependencies using the instructions in the README.
5. Configure local environment variables using the documented examples.
6. Run the available tests before submitting changes.

Never commit API keys, Firebase service-account credentials, access tokens, passwords, or confidential banking information.

## 3. Branch and Pull Request Guidelines

Use descriptive branch names, such as:

- `feature/improve-rag-retrieval`
- `fix/firebase-authentication`
- `docs/update-architecture`
- `test/add-policy-validation`

Submit pull requests against the `main` branch.

Each pull request should include:

- A clear explanation of the change.
- The problem being addressed.
- Relevant testing performed.
- Screenshots or examples where useful.
- Any security or compatibility implications.

## 4. Coding Standards

- Follow the existing project structure and coding conventions.
- Keep changes focused and maintainable.
- Validate all external inputs.
- Avoid logging sensitive user information.
- Include appropriate tests for new functionality.
- Document significant architectural changes.

## 5. Banking and AI Safety

This project is intended for development, demonstration, and responsible experimentation.

- Use synthetic data for demonstrations and tests.
- Do not submit real customer information or confidential banking records.
- Clearly distinguish retrieved policy information from AI-generated explanations.
- Preserve policy versioning and source attribution.
- Do not represent AI-generated output as an authorised banking decision.
- Retain appropriate human review for high-impact banking decisions.

## 6. Security Vulnerabilities

Please do not disclose security vulnerabilities in public issues.

Follow the responsible disclosure process described in `SECURITY.md`.
