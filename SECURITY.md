# Security Policy

## Supported Versions

Security fixes will be considered for the latest version of
AI Banker Transformation Copilot available in the main branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public
GitHub issues or public discussions.

Use GitHub's Private Vulnerability Reporting feature for this
repository to submit a confidential report.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected components.
- Any suggested mitigation, if available.

## What to Expect

The maintainers will review submitted reports and may request
additional information.

Please allow reasonable time for investigation and remediation
before publicly disclosing a vulnerability.

## Security and Banking Data

- Never submit real customer information or confidential banking records.
- Never include API keys, passwords, access tokens, or service-account credentials.
- Use synthetic data for demonstrations and testing.
