# Support

Thanks for trying AI Banker Transformation Copilot.

## Where to ask

- **Bug reports:** Open a GitHub issue and use the Bug Report template.
- **Feature ideas:** Open a GitHub issue and use the Feature Request template.
- **How-to questions:** Start a GitHub Discussion if Discussions are enabled; otherwise open an issue labelled `question`.
- **Security vulnerabilities:** Do not use public issues. Follow [SECURITY.md](SECURITY.md).

## Before asking

Please include the project version or commit, operating system, Node.js version, steps to reproduce, expected behaviour, actual behaviour, and relevant redacted logs.

Never post API keys, access tokens, service-account files, passwords, real customer records, account numbers, or confidential banking information.

## Scope and expectations

This is a community project maintained on a best-effort basis. No response time or support SLA is guaranteed. This repository is not an official support channel for Google, Firebase, Anthropic, or any bank.
